# 饒恕速查（Forgiveness Quick Reference）

一頁白話的饒恕查詢工具，給一般讀者手機閱讀。十秒內找到自己的處境，讀到「那麼」就能行動。

**線上版：** https://tomclin.github.io/forgiveness-quickref/

## 這是什麼

一句話：**放下報仇，不放下公道。**

把「饒恕」拆成三件常被混在一起的事：

- **心裡（放手）**——放下報復與怨恨，不以對方道歉為條件。
- **關係（和好）**——是持續朝向的方向，但要對方認錯、補償，信任靠行動與時間重建。
- **公道（照樣算）**——該調解就調解，該負的責任、該報警的照樣走。

頁面提供 12 種處境卡（「我受傷了／我傷了人／我在旁邊／群體之間」），每張以「如果 → 那麼 → 為什麼 → 怎麼做 → 經文」呈現，可依身分篩選、關鍵字搜尋。

## 使用須知

- 這是一份幫助辨認處境的整理，**不能取代牧養、輔導或法律專業的協助**。
- 遇到「饒恕是否要等對方悔改」「信徒能不能打官司」這類問題，教會傳統仍有不同理解；本頁提供一種讀法，不是定論。詳見頁面最底的兩條附註。
- 若你正面臨危險：在台灣，緊急狀況撥 **110**，家暴、性侵害可撥 **113** 保護專線。饒恕可以之後再談。
